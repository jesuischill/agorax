# AgoraX

Réseau social Next.js + Supabase.

## Fonctionnalités
- Auth email/mot de passe
- Profils
- Feed
- Publications texte/image
- Likes
- Abonnements
- Stories de 24 h
- Upload média
- Messagerie directe temps réel
- Découverte de profils

## Configuration
Créer `.env.local` à partir de `.env.local.example`.

Variables :
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=

Puis exécuter `supabase/schema.sql` dans le SQL Editor de Supabase.
